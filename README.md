# homebrew-freedisk

Homebrew tap for **freedisk**, a macOS disk-audit CLI. Scan never deletes.

```bash
brew install --HEAD CiprianSpiridon/freedisk/freedisk
```

After a stable formula URL is filled:

```bash
brew install CiprianSpiridon/freedisk/freedisk
```

Source: https://github.com/CiprianSpiridon/free-disk-space
